Benchmarks and verification ​

MILEVA's 2-D science path is the spherical annulus (radial measure r2dr, Hernlund & Tackley 2008) and its 3-D path is the Yin-Yang spherical shell. Evidence that the code solves the equations it claims to solve comes in three kinds, and this page keeps them apart:

KindWhat it showsExamples
Verification against published resultsThe same physical problem, solved by an independent code in the same geometry, gives the same numbers as the published tables.Hernlund & Tackley (2008) spherical-annulus tables; the Annulus column of Fleury et al. (2024); the Kageyama & Sato (2004) Yin-Yang rotation formulas.
Verification against exact identitiesA property every correct discretisation must satisfy, independent of any reference value: conservation, an exact null mode, an energy identity.Nu = 1 on conduction, closed energy budget, work = dissipation, rigid rotation annihilated, G=−BT.
RegressionThe code agrees with itself: two solvers on the same matrix, the serial and distributed assemblies, a stored earlier result. It protects against change, not against a wrong operator.MUMPS against UMFPACK, multigrid against MUMPS, serial against distributed 3-D assembly.

Same geometry

The 2-D path is compared only with spherical-annulus references (Hernlund & Tackley 2008; the Annulus column of Fleury et al. 2024). Cartesian box benchmarks, cylindrical annulus cases and Fleury et al.'s scaled cylinder column describe other geometries and are not used as targets.

Running the benchmark driver ​

benchmarks/hernlund_tackley_annulus.jl sets up the reference problem from scratch: it clears every optional physics flag, then switches on only what the case needs.

bash
# case, Nr, seeded wavenumber m (default 6); Nt = 8 Nr
julia --project=. benchmarks/hernlund_tackley_annulus.jl HT4 64
julia --project=. benchmarks/hernlund_tackley_annulus.jl HT5 128 6
julia --project=. benchmarks/hernlund_tackley_annulus.jl HTV5 64

# Fleury et al. (2024) annulus, Ra = 10^k, aspect ratio from MILEVA_F
MILEVA_F=0.6 julia --project=. benchmarks/hernlund_tackley_annulus.jl FL5 64
CaseRaViscosityReference
HT4, HT5, HT6104, 105, 106isoviscousH&T 2008 Table 1
HTV5, HTV6105, 106η=exp⁡[13.8156(0.5−T′)], contrast 106H&T 2008 Table 2
FL4 … FL8104 … 108isoviscousFleury et al. 2024, benchmarks/reference/fleury2024/

The setup is a Boussinesq, basally heated shell with free-slip walls, isothermal boundaries, no net rotation and a uniform grid. The layer is 1000 km thick with f=rin/rout=1.22/2.22=0.5495 for the H&T cases, and the viscosity is chosen to give the requested

Ra=ρ0gαΔTD3κη.

The variable-viscosity cases use the Frank-Kamenetskii "simple" form with θFK=ln⁡106 and η=ηRa at T′=0.5. The run goes to 0.6 thermal diffusion times (D2/κ is 31 688 Myr here), averages Nutop and Vrms (in units of κ/D) over the last third, and fits a straight line through that window. If the trend exceeds the larger of 2 % (Nu) / 5 % (Vrms) and the reference's own published fluctuation, it prints a NOT CONVERGED flag. Output goes to output/benchmarks/ht2008_<case>_N<Nr>…/, including diagnostics.csv with the energy budget.

These runs take hours to days at Nr = 64 and above. Use MILEVA_MAXSTEPS=<n> and MILEVA_OUTTAG=<tag> for short probes.

The "T on grid (TVD)" row below is reproduced with the env knob MILEVA_TGRID=1, which sets cfg.temperatureOnGrid = true (TVD advection on the grid) and adds the suffix _gridT to the output directory:

bash
MILEVA_TGRID=1 julia --project=. benchmarks/hernlund_tackley_annulus.jl HT5 64

How to read it:

  • Ra = 104. Nu converges from above through the reference value (4.24, 4.14, 4.05 at Nr = 32, 64, 128, reference 4.18). The reference itself was computed at 32 × 256. Vrms is 35.4, 35.1, 35.0 against 37.7, steady with resolution.

  • Ra = 105. Vrms is 156.9 to 159.6 for m=6 and 156.4 for m=8, reference 160. Nu is 8.76, 8.88, 8.90 from Nr = 32 to 128 against 7.39, unchanged by resolution, and the grid TVD path gives the same Nu (8.97). Nu depends on the planform: seeded m=4,6,8 give 9.05, 8.88, 8.40. The planform of the reference run is not reported.

  • Ra = 105 at contrast 106 (the case that exercises the variable-viscosity operator): Vrms at Nr = 64 is 535.8 against the paper's 463 ± 90, and Nu rises toward the reference with resolution (4.66 at Nr = 32, 5.18 at Nr = 64, reference 5.71 ± 0.1).

  • Ra = 106 (HT6, HTV6): the driver supports these cases; no measurement is listed yet.

When quoting these numbers, state the seeded wavenumber cfg.m_wavenumber: more than one planform is stable at these Rayleigh numbers and the seed decides which one the run lands in. The reference has no error bars or convergence study, so the comparison is verification against published results.

Fleury et al. (2024), Annulus column ​

Fleury, Plesa, Hüttig & Breuer (2024, G3 25, doi 10.1029/2023GC011114) solved basally heated isoviscous convection in the 3-D sphere, the spherical annulus and a scaled cylinder, for f=0.2 to 0.8 and Ra = 104 to 108. Their tables (Zenodo doi 10.5281/zenodo.8047757) are in benchmarks/reference/fleury2024/, copied unmodified; the driver reads only the Annulus column. Their definitions match H&T (measure 2r2drdϕ, same Ra, Nutop normalised by f). Two differences matter when comparing: Fleury et al. start from a 5 % random perturbation with an unreported planform (MILEVA seeds m=6), and their top gradient is a one-sided difference between the last two shells.

Measured at Nr × Nt = 64 × 512:

Exact identities ​

These hold for any correct discretisation, whatever any reference says. Each is asserted by a test in tests/, run by tests/run_tests.jl.

Two of these identities, recomputed by docs/scripts/plot_conservation.jl with MILEVA's own diffuse_temperature, compute_diagnostics and assemble_stokes in the spherical annulus. Left: the conducting Nusselt number converges to 1 at second order, with the top and bottom values identical. Right: |W/D−1| on an exponential radial viscosity ramp shrinks under refinement at every viscosity contrast from 1 to 106.

Conduction: Nu = 1 and Nu_top = Nu_bot ​

tests/test_nusselt_conduction.jl produces the conducting steady state with the diffusion solver itself (backward Euler, Δt≫D2/κ) and evaluates compute_diagnostics on it. The wall flux is the one the diffusion operator uses, k(Tbc−Twall cell)/(Δr/2), with the Dirichlet value held at the face.

spherical annulus, |Nu−1|8.1e-42.0e-45.1e-5

Second-order convergence, and Nutop=Nubot to round-off at every resolution (asserted to a relative 1e-9).

Energy budget closure ​

The same test takes one backward-Euler step from an arbitrary field and checks that the change of thermal energy equals the net wall power computed from the reported wall gradients:

ρcpddt∑cTc|c|=Pbot−Ptop.

Measured relative residual: 2.1e-15 (spherical), 5.9e-15 (cylindrical). With uniform internal heating the applied power equals the prescribed power to 1e-12 and the residual stays at 6e-15.

tests/test_marker_energy.jl checks that one marker temperature step (projection, grid diffusion, sub-grid relaxation, hand-back) moves exactly the energy the grid solver computed, ∑mwmΔTm=∑cΔTc|c|:

PathRelative residual
2-D spherical annulus, exact delivery5.3e-15
2-D cylindrical annulus, exact delivery2.6e-15
3-D Yin patch, exact delivery5.1e-11
3-D Yin patch, production cap deliveryScaleMax = 27.2e-2

In the last row the cap applies at Yin-patch edge nodes, which carry half-cell marker support.

In a running model the same bookkeeping is logged every diagEvery steps as budget_resid in diagnostics.csv: the change of thermal energy against the boundary and internal power accumulated every step with the diffusion solver's own theta weighting (boundary_power, utils/diagnostics_csv.jl), normalised by the larger of the surface and internal power. A conservative run gives about zero. Measured values on the H&T runs are in the tables above (|budget_resid| ≤ 0.002 on the marker path). The grid TVD path is slightly non-conservative (+0.011), and marker reseeding is the one remaining non-conservative operation on the marker path.

Work equals dissipation (2-D) ​

For any Stokes solution with no-normal-flow walls the buoyancy work equals the viscous dissipation, at any viscosity field:

W=∫f⋅vdV=∫2ηε˙:ε˙dV=∫4ηε˙II2dV=D,W/D=1.

Unlike rigid rotation, on which ε˙≡0, this identity exercises the viscosity-gradient part of the operator. Measured on a fixed analytic load, Nr = 24 / 48 / 96:

ContrastW/D
10.995 / 0.999 / 1.000

tests/test_annulus_operator.jl asserts W>0, D>0 and |W/D−1|<0.05 in the spherical annulus on an exponential radial viscosity ramp. Measured at Nr = 32:

At 108, |W/D−1| falls from 0.021 (Nr = 32) to 0.0063 (Nr = 64).

Rigid rotation is annihilated (2-D) ​

Rigid rotation has ε˙≡0, so it is an exact null mode of ∇⋅(2ηε˙) in every geometry. The operator returns a relative residual of 1.5e-16, 1.4e-16 and 2.3e-16 at Nr = 12, 24, 48 in the spherical annulus. tests/test_annulus_operator.jl asserts a residual below 1e-12.

Rigid rotation (3-D) ​

With cfg.useCurvatureTerms = true (the default, the full spherical deviatoric stress) the rigid-rotation residual is 2.0e-16 / 2.5e-16 / 2.5e-16 at Nr = 8 / 12 / 16, independent of the viscosity field. tests/test_spherical_operator_nullmode.jl pins both branches.

Yin-Yang geometry ​

tests/test_yy_rotation_vs_ks2004.jl checks the vector rotation between the patches against Kageyama & Sato (2004), Eqs. 22-23; agreement is to machine precision. This is verification against a published analytic formula.

The 3-D checks on this page are exact identities of the operator and the Yin-Yang rotation; a comparison of Nu and Vrms with a published 3-D shell benchmark is not listed yet. How the patches are coupled across their seam is described on the Yin-Yang grid page.

Run the suite with

bash
JULIA_NUM_THREADS=4 julia --project=. tests/run_tests.jl

It reports 1404 passes, 0 failures, 0 errors in about five minutes.

Scripts outside the runner: tests/test_amr_full.jl (its baseline iteration count of 40 predates the current 3-D solver, which converges in 31), and tests/test_mdpi_eta_contrast.jl, tests/test_vcycle_visc_contrast_sweep.jl, tests/test_arrhenius_viscosity.jl, tests/test_fk_viscosity.jl and the smoke_* chunk scripts, which print their results rather than asserting them.
