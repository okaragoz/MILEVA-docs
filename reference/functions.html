Function reference ​

MILEVA is a flat-include code, not a package module. include/mileva.jl includes every source file in dependency order (configuration, grid, basic utilities, markers, physics, solvers, the MPI scaffold, I/O, visualization), and main_SphCon.jl defines the time loop on top of it, so all functions live in one namespace. This page lists the public entry points grouped by directory. Signatures are abbreviated: keyword arguments are omitted unless they matter for use. Follow the file paths for the full definitions; most files open with a header comment that explains the method.

julia
using Plots                       # visualization/plot_panels.jl needs it loaded
include("include/mileva.jl")
include("main_SphCon.jl")

Conventions used below: cfg::SimConfig, mat::MaterialProperties and temp::TemperatureConditions are the configuration structs (Parameter reference); grid is a MutableGrid2D or MutableGrid3D from setup_grid; M::Markers is the marker cloud; ETA the cell-centred viscosity, buoy the cell-centred buoyancy, Tg the grid temperature. Most functions dispatch on the grid type, so the same name has a 2-D (Matrix) and a 3-D (Array{Float64,3}) method.

Entry points ​

Function / scriptPurposeFile
main_SphCon(cfg, mat, temp)The time loop: grid and markers, then per step viscosity, buoyancy, Stokes (with Picard sweeps when a yield law is active), no-net-rotation projection, marker advection, reseeding, temperature advection and diffusion, melting and composition, diagnostics, output, checkpoints. Returns a NamedTuple of time series (time in Myr, Vrms, Vrms_nd, Nu_top, Nu_bot, Tmean, q_cmb, lid and surface diagnostics) merged with the final state (Tg, Vr, Vt, and in 3-D Vph, yang, Tg_yang).main_SphCon.jl

bin/mileva run / run-mpi / test / docs / versionShell launcher: serial run, MPI launch, a single test file (default smoke_stokes_3d_mg), docs build.bin/mileva
bin/run_mpi.jl <param.jl>Generic MPI driver around solve_stokes_distributed! for a config-only parameter file.bin/run_mpi.jl

The order in which main_SphCon calls the functions listed on this page. Grey boxes run once at start-up; the coloured boxes run every step, grouped into material properties (orange), flow (blue), transport (green), temperature and diagnostics (purple) and output (grey). Optional stages are skipped when their cfg switch is off, and the dashed loop repeats rheology and Stokes until the velocity settles when a yield law is active.

Refinement prototype

solvers/amr/ (indicators.jl, refine.jl, coarsen.jl, hanging_nodes.jl) is an indicator prototype for dynamic refinement. include/mileva.jl does not include it and validate! refuses cfg.useAMR = true. It is exercised only by tests/test_amr_indicators.jl and tests/test_amr_full.jl.
